Система учёта заявок (RequestSystem)

Назначение
Система предназначена для регистрации, обработки и контроля обращений пользователей организации. Позволяет создавать заявки, назначать исполнителей, отслеживать статусы и формировать отчёты.

Функции
- Регистрация заявки с уникальным номером
- Назначение исполнителя оператором
- Статусы: Новая, В работе, Выполнена, Закрыта
- Не менее 4 категорий заявок
- Комментарии и история статусов
- Фильтрация заявок по статусу, категории, исполнителю
- Отчёты по заявкам за период
- Роли: администратор, оператор, исполнитель, заявитель

Стек
Python 3.12+, Git, SQLite (план), draw.io.

Структура
- `docs/` — документация (ТЗ, диаграммы, отчёты)
- `src/` — исходный код
- `tests/` — тесты
